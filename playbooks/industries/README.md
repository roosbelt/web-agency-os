# Industry Playbooks

Estos playbooks adaptan el flujo general de Web Agency OS al modelo comercial, riesgos y señales de confianza de cada industria. No sustituyen investigación ni brief: ayudan a formular mejores preguntas y a evitar estructuras genéricas.

## Cómo usarlos

1. Selecciona un playbook primario según la fuente principal de ingresos del cliente. Si el negocio es híbrido, registra un playbook secundario y resuelve conflictos explícitamente.
2. Completa `templates/industry-discovery-template.md` antes de cerrar estrategia.
3. Usa el playbook como lente en Research, Brand, UX/CRO, Copy, SEO, Visual y Frontend.
4. Conserva solo secciones que respondan a evidencia, intención comercial u objeciones reales.
5. Marca `[POR CONFIRMAR]` y bloquea publicación cuando falten claims, precios, permisos, licencias, políticas o destinos operativos críticos.
