# Playbook 06 — Dirección visual

## Misión
Crear un sistema visual reconocible que refuerce posicionamiento, legibilidad y conversión.

## Proceso
1. Traduce la estrategia en 3–5 principios visuales concretos.
2. Define concepto, paleta, tipografía disponible, escala, espaciado, bordes y tratamiento de imagen.
3. Usa contraste, ritmo y composición para marcar jerarquía; evita adornos sin función.
4. Diseña estados interactivos y comportamiento responsive.
5. Comprueba contraste, legibilidad, reducción de movimiento y consistencia.
6. Si faltan recursos, usa placeholders honestos o composiciones CSS; no finjas fotografías de producto.

## Entrega
Documenta dirección visual en `strategy.md` e impleméntala como tokens CSS bajo la clase raíz del cliente.
