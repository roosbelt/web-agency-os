## Publicación
1. Crea o abre la página en WordPress.
2. Añade un bloque de HTML personalizado y pega `wordpress-body.html`.
3. Añade `style.css` al CSS adicional del tema, al área CSS del editor o al mecanismo aprobado del sitio.
4. Configura enlaces, recursos y metadatos SEO confirmados.
5. Previsualiza y publica solo después de QA.
