# Copy-ready exports — JAPA Soluciones

## Complete page
1. Paste `full-page-copy-ready.html` into a WordPress Custom HTML block or approved page template.
2. Add `full-page-copy-ready.css` to the site/page custom CSS area.
3. Replace placeholders and pending contact states only with approved data.

## Individual modules
Each numbered module has an independent HTML and CSS pair. Paste both files for that module; do not remove `.wao-japa`. If multiple modules share a page, prefer the full-page CSS once to avoid repeated rules.

## Before publishing
Confirm service catalog/scope, coverage, WhatsApp, projects/photos and permissions, commercial process, policies, legal information, SEO metadata and QA in the real WordPress theme.
