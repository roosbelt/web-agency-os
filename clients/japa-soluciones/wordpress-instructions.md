# WordPress instructions — JAPA Soluciones

## Current state
**WordPress-ready prototype; Publish-ready blocked.** Contact CTA intentionally remains non-interactive until WhatsApp and process are confirmed.

## Full-page installation
1. Copy `wordpress-body.html` into a WordPress Custom HTML block or approved template.
2. Add `style.css` to page/site custom CSS.
3. Keep the `.wao-japa` root wrapper.
4. Compare against `preview.html` and test within the real theme.

## Modular installation
Use pairs in `exports/` or source modules in `modules/`. Follow `exports/README.md` and avoid adding the same shared CSS repeatedly.

## Required replacements
- Activate WhatsApp only after receiving and testing the official number/message.
- Replace placeholders with owned/authorized images, dimensions and approved alt text.
- Replace provisional service wording with verified catalog, scope, coverage and exclusions.
- Add verified trust proof, commercial process, policies, legal and final SEO.

## QA after installation
Test at mobile/tablet/desktop, keyboard/focus, FAQ, anchors, CTA destination, contrast, theme/plugin conflicts, performance and forms/contact behavior. Do not publish while blockers remain.
